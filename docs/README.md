## Recording tips

- macOS QuickTime Player → File → New Screen Recording → pick a region around the sidepanel
- For GIFs of the agent in action, narrate the user-visible result with on-screen captions or arrows; avoid internal tool names such as `read_page` or `a11y tree`.
- Crop tightly; empty browser chrome around the sidepanel hurts engagement.

Once recorded, drop the files in this directory and update the image links in the top-level README.
